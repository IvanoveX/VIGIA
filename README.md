# VIGIA — protótipo de interface

Protótipo navegável (só front-end, dados simulados) do VIGIA, projeto de prevenção de quedas da Fábrica de Projetos Ágeis IV (IA, UNIMAR). Cliente: Hospital Beneficente Unimar.

- Rodar local: `npm install` e depois `npm run dev`
- Rodar offline: `npm run build` e depois `npm run preview`

Especificação completa em `SPEC.md`.
